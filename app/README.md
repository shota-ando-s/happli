# Happli（はぷり）— Excelマクロの置き換え

現場のExcelマクロがやっている作業を、ブラウザだけで動くHTMLアプリにしたものです。
ファイルは端末のブラウザの中だけで処理され、外部には送信されません。
（例外として、更新版があるかどうかを1日1回 `https://shota-ando-s.github.io/happli/version.json` に確かめに行きます。送るデータはありません。）

## 使い方
- **ローカル**: `index.html` をダブルクリックして開く（Chrome / Edge）
- **公開**: このフォルダ一式を静的ホスティングにそのまま置く（サーバー処理は不要）

## 版と更新
どの画面も見出しの右上に版のバッジが出ます。最新なら「最新版です」、新しい版が出ていれば「更新版があります」と出て、押すとダウンロードの案内が開きます。オフラインのときは版名だけが出ます。

新しい版を出すときは、`main` ブランチで `scripts/release.sh`（版名を省略すると今日の日付）を実行します。版名の書き換え・タグ付け、配布用 zip の作成と公開用リポジトリ [shota-ando-s/happli](https://github.com/shota-ando-s/happli) のリリースへの添付、`version.json` の更新までをまとめて行います。

どの画面でも、左のメニューにすべての機能がカテゴリ別のツリーで並びます。よく使う機能は横の ☆ を押すと、メニューの上の「お気に入り」に並びます（もう一度押すと外れます）。狭い画面では、左上のボタンでメニューを開きます。

## 開発
- テスト: `npm test`（Node.js 22 で確認。依存パッケージなし）
- 構成と方針: `docs/dev/context.md`
- 計画とタスク: `docs/dev/plans/macro-apps/`
- 機能を追加するときの規約: `docs/dev/plans/macro-apps/contract.md`
- 公開前に確認が要る点: `docs/dev/kakunin-log.md`
- 調査資料と設計判断の経緯: `docs/research/`

機能の追加は、`assets/js/core/registry.js` のカタログに1件足し（icon・area・input・output も書く）、`apps/` にページ、`assets/js/apps/` にロジック、`tests/` にテストを置きます。

## デザイン
画面は [Tabler](https://github.com/tabler/tabler)（Bootstrap 5 ベース）で作っています。Tabler 本体とアイコンは `assets/vendor/tabler` に同梱しているので、オフラインやファイルのダブルクリックでも同じ見た目になります。端末の設定に合わせてダークモードに切り替わります。各機能は「手順カード」を上から順に進める形にそろえています。
